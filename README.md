# 运行指南

## 第一步：解决权限问题，优先找管理员在后台添加您为开发者，这样获得的开发权限是最大的。如果没有被添加为开发者，还有一个办法，就是自己去申请一个小程序测试号，拿到测试号的AppID(小程序ID)，一般是这样的：wxdad3559d1684ssfb。然后点微信开发者工具的右上角头像左边的三个横杠（详情），在基本信息，有一个AppId，点击修改，把这个测试号的AppId填进去。	这样也可以运行起来。

## 第二步：安装TS插件
```bash
npm install -D typescript miniprogram-api-typings
```
参数说明：

-D（或 --save-dev）：将其安装到 devDependencies 中（开发依赖），因为类型定义只在开发时需要

## 第三步：npm 构建，点微信开发者工具的菜单栏 工具，然后点 构建 npm
构建完毕后，会在根目录生成  miniprogram_npm文件夹，里面是 tdesign-miniprogram

## 第四步：编译预览即可

## 第五步：登录

小程序的开发版是用手机号和密码登录的，需要先在自塾官网注册好账号。小程序的登录手机号和密码和官网登录用的完全一样。如果没有在官网注册过账号，也可以点以游客身份登入，这时候会用一些Mock数据来填充一些页面。
