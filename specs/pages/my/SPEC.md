## 4. 关键路径

- **文件**：`pages/my/my.{ts, wxml, wxss}`（约 350 行 / 200 行 / 420 行）
- **API**：
  - 用户信息：`wx.getStorageSync('userInfo')` + `app.globalData.userInfo`
  - 统计：`GET /api/users/fetch_reports/{user_id}` + `/fetch_shuzhi/{user_id}`
  - **我的方舟**：`GET /api/learn/ark/user/list` → 返回 `{preparing, sailing, finished, closed}` ✅ 已加
- **跳转**：
  - 方舟卡片 → `/pages/ark-detail/index?arkId=...`（B2 完成后已改）
  - 菜单项 → 各目标页面

## 5. 我的方舟区块（**spec 002 · commit `a2e32a5`**）

### 5.1 区块结构
- 标题：🚢 我的方舟 + 数量统计（N 个）
- 列表项（精简卡片）：
  - 顶部：方舟名（大字）+ 状态 tag（筹建中/在航/已成舟/已解散）
  - 中间：课程名
  - 底部：进度条 + 百分比 + 成员数
- 空状态：🛶 + "暂未加入任何方舟" + 引导文案

### 5.2 状态 tag 颜色
| 状态 | class | 颜色 |
|------|-------|------|
| 筹建中 | `tag-prep` | 灰 #999 |
| 在航 | `tag-sail` | 紫 #aa00ff |
| 已成舟 | `tag-done` | 绿 #67c23a |
| 已解散 | `tag-closed` | 灰 #999 |

### 5.3 列表合并逻辑
4 个分组（preparing/sailing/finished/closed）合并，按 `create_time` 倒序排列（最新在前）。
